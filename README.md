# 🐾 Pet Schedule Bot

Telegram-бот для совместного управления питомцами, процедурами и расписаниями с автоматическим расчётом задач на каждый день.

Проект рассчитан на **нескольких пользователей**, работающих с **одной общей базой данных**.

---

## ✨ Возможности

### 🐾 Питомцы

* Создание питомцев
* Выбор существующих
* Редактирование данных
* Деактивация

### 🧪 Процедуры

* Создание процедур
* Описание процедур
* Редактирование
* Деактивация

### 📅 Расписания

* Привязка процедур к питомцам
* Типы расписаний:

  * каждые *X* дней
  * по дням недели
  * раз в месяц
  * раз в год
  * конкретная дата
* Редактирование периодичности
* Деактивация расписаний

### 📋 Задания на сегодня

* Автоматический расчёт задач на текущий день
* Общий inline-чеклист для всех пользователей
* Хранение статуса выполнения
* Защита от устаревших кнопок

## ▶️ Запуск проекта

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Создание бота

Перед запуском создайте в корневой директории файл .env и внесите токен,
полученный в приложении @BotFather

```bash
BOT_TOKEN="ваш_токен"
```

### 3. Запуск бота

```bash
python main.py
```

При первом запуске база данных будет создана автоматически.
